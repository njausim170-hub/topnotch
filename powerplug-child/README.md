# TopNotch Mall Child Theme

Activate this child theme (Appearance -> Themes) and put ALL customizations here so parent updates never overwrite your work.

- `style.css` - your custom CSS and brand-color overrides (loaded after the parent).
- `functions.php` - enqueues the parent stylesheet and exposes the example `powerplug_business_details` filter.

Parent theme required: **TopNotch Mall (PowerPlug engine) 2.10.0+**.
